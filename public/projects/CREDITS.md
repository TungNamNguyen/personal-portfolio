# Project cover photos

All four are CC0 (public domain dedication) — free for commercial use, no
attribution required. Recorded here for provenance, not obligation. Found via
the Openverse API, cropped to 1000x380 and re-encoded as WebP.

| File | Source | Licence |
| --- | --- | --- |
| `aerostream.webp` | StockSnap.io `6FI8W1L305` — airliner wing above cloud | CC0 |
| `templates.webp` | Wikimedia Commons — *Maersk Ferrol 2012 Bremerhaven (cropped)* | CC0 |
| `gitlab.webp` | StockSnap.io `1STVFMTBJY` — syntax-highlighted source | CC0 |
| `fall-detection.webp` | StockSnap.io `E8U0GNCPI8` — dome surveillance camera | CC0 |

To swap one out, drop a replacement in this folder and point `image` at it in
`src/constants.tsx`. Removing the `image` line falls back to the drawn band in
`src/projectCovers.tsx`.
